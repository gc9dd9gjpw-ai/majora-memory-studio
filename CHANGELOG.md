# Changelog

## 1.2.2 — Public beta

- Light interface with white inputs and purple accents.
- Visible resource capacities and normal game maxima.
- Navigation in several rows with full section names.
- Regional panels embedded in the main window.
- Pending amounts retained across language changes.
- Regional health expressed in hearts; invalid fractional input rejected without silent rounding.

This release focuses on presentation and input preservation. It does not declare complete planned compatibility or full console validation.
